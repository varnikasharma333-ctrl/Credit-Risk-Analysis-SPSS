# Credit Risk Analysis and Loan Default Prediction Using SPSS

## 1. Project Overview

This project focuses on analyzing loan applicant data using IBM SPSS Statistics to understand factors associated with loan default.

The project uses statistical analysis and predictive analytics techniques to support better credit risk assessment and loan approval decisions.

## 2. Business Problem

FinTrust Bank has experienced an increase in loan defaults. The bank wants to understand which applicant characteristics may be associated with loan default and how these insights can support better lending decisions.

## 3. Project Objectives

* Understand the loan applicant dataset.
* Identify and examine missing values, duplicate records, and potential outliers.
* Perform exploratory data analysis using charts and frequency tables.
* Calculate descriptive statistics.
* Examine relationships between selected financial variables and loan default.
* Develop a suitable regression model to investigate potential predictors of loan default.
* Suggest data-driven recommendations for credit risk management.

## 4. Dataset Description

The provided dataset contains 200 applicant records and 20 variables.

Key variables include:

* Age
* Gender
* Monthly Income
* Existing Loan Amount
* Loan Amount Applied
* Credit Score
* Previous Defaults
* Savings Balance
* EMI-Income Ratio
* Loan Approved
* Loan Default

The target variable is Loan_Default.

## 5. Tools Used

* IBM SPSS Statistics
* Microsoft Excel
* GitHub

## 6. Methodology

### Data Preparation

* Imported the Excel dataset into SPSS.
* Checked missing values.
* Checked duplicate records.
* Examined potential outliers using box plots.
* Reviewed variable types and measurement levels.

### Exploratory Data Analysis

* Created frequency tables.
* Generated bar charts and pie charts.
* Examined numerical distributions using histograms and box plots.

### Descriptive Statistics

The analysis includes measures such as mean, median, mode, standard deviation, variance, skewness, and kurtosis.

### Correlation Analysis

The following relationships are examined:

* Monthly Income and Loan Amount Applied
* Credit Score and Loan Default
* Savings Balance and Loan Default
* EMI-Income Ratio and Loan Default

### Regression Analysis

A binary logistic regression model is planned to examine the relationship between selected applicant characteristics and the binary loan-default outcome.

## 7. Results and Findings

Final statistical findings will be documented after completing the correlation and regression analyses.

## 8. Recommendations

Recommendations will be based on the actual statistical results and their relevance to credit risk management.

## 9. Limitations

The findings are based on the provided dataset and should not be generalized to all loan applicants without further validation.

Any predictive model should be evaluated before being used for real lending decisions.

## 10. Conclusion

This project demonstrates the use of IBM SPSS Statistics for data preparation, exploratory analysis, descriptive statistics, correlation analysis, and predictive modelling in a credit risk context.
